## 行为与边界

- 新增 `active-page-cache-shell-v1`，区分唯一当前页和完整隐藏缓存页。每页的 main/editor、归属与隐藏方式均验证，未知额外编辑器、可见缓存页、重复当前页和外部区域继续拒绝。
- 打开看板时重新绑定当前完整工作区，隐藏会话正文和标题栏；保留所有缓存编辑器及同一 iframe。当前 main 已有而 editor 尚未挂载时，恢复原生视图、禁用入口并在原有预算内等待；该中间态不授予能力。
- 刷新与恢复都重新检查结构和同一原生身份。短时空 session / negative proof 只在原 4 秒 / 8 秒预算内完整复核一次，不复用旧成功、不改绑目标。
- CSP 刷新保护所有缓存草稿，包括隐藏文字、空格、图片和富文本。自动草稿版本、项目和空编辑器模型门禁不增加；日常模式仍为用户手动复制与确认发送。
- 本轮不改变任务 API、数据库、生产服务或官方 UI 原型的业务接入范围，没有模型调用。
