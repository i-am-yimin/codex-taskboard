用户确认：任务看板和会话是同级页面，再次点击已选中的“任务看板”保持当前页，通过具体会话入口切回。0.1.6 的原验收仅证明导航收起、构建和安装等分项，没有覆盖这一完整行为，用户复验未通过；旧标签与资产保持固定。

## 行为与边界

- 真实 Codex `26.1016.8622.0` 的会话标题栏位于主内容区之外，使用固定定位。0.1.7 将看板与完整工作区作为兄弟视图，进入看板时原工作区不可见且不可交互，不再通过巨大 z-index 覆盖正文。
- 看板与原会话只呈现一个当前页；原生内部会话标记、聊天编辑器和 iframe 保持挂载。切回恢复原有外观、可访问状态和焦点。
- 明确拒绝缺失、重复、包含侧栏或越界的工作区标记。宿主版本、进程、用户、会话、监听者、唯一页面、nonce 与 CSP 校验保持。
