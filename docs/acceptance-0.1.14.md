# 0.1.14 版本验收

状态：2026-11-14，Windows x64 未签名预发布准备中。用户已授权打包与发布；本记录尚未确认固定标签、CI、安装器、来源证明、实机安装或公开下载通过。已发布 0.1.13 的标签和资产保持固定，独立服务器仍为 `0.1.5-preview.2`。

## 本版范围

桌面侧栏只保留品牌与任务看板/列表，账号操作统一到顶栏。空间菜单进入“空间设置”，账号菜单进入独立的“连接与本机”；侧栏隐藏时恢复页头视图切换。看板按实际内容宽度换行，五个状态在默认 1320px 窗口下为 4+1，窄窗口所有状态及任务操作仍可纵向到达。

本次仅客户端发布准备，没有业务逻辑、API、数据库迁移、依赖或安全边界变化。四套主题、权限、离线只读、日常 Codex 数据、原生归属、结构、CSP、来源/nonce 与草稿保护沿用。客户端安装不会升级独立服务器。官方 global/thread UI 合成原型不进入产品运行时。

## 已有实施阶段证据

[桌面布局实施验收](acceptance-desktop-shell.md)记录版本更新前的最终源码、浏览器替身、截图、失败与修复。该阶段 `pnpm check` 完成：289 项通过，65 项依赖独立数据库的测试跳过；四主题、五状态、长中文、窄屏、独立无 Tauri 内嵌、菜单范围与焦点等 112 个浏览器项目用例通过。证据修正的重复复验单列，不重复计数。

上述证据证明实施阶段的源码与浏览器布局，不证明 0.1.14 固定标签的完整 CI、Windows 原生窗口、真实 Codex 宿主或最终安装包。
