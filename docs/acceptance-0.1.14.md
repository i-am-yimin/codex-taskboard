# 0.1.14 版本验收

状态：2026-11-14，Windows x64 未签名预发布已公开。固定标签 CI、最终载荷、随包运行时、Linux 归档、严格来源证明、最终包原位升级与默认窗口实机检查已通过；Astra 发布前独立验收与发布后匿名完整下载均通过。原生窄窗、旧版恢复拒绝、长期稳定性与未来宿主范围单列；既有标签和资产保持固定，独立服务器仍为 `0.1.5-preview.2`。

## 本版范围

桌面侧栏只保留品牌与任务看板/列表，账号操作统一到顶栏。空间菜单进入“空间设置”，账号菜单进入独立的“连接与本机”；侧栏隐藏时恢复页头视图切换。看板按实际内容宽度换行，五个状态在默认 1320px 窗口下为 4+1，窄窗口所有状态及任务操作仍可纵向到达。

本次仅整合客户端导航与布局，没有业务逻辑、API、数据库迁移、依赖或安全边界变化。四套主题、权限、离线只读、日常 Codex 数据、原生归属、结构、CSP、来源/nonce 与草稿保护沿用；本版不包含连接恢复生命周期修复。客户端安装不会升级独立服务器。官方 global/thread UI 合成原型不进入产品运行时。

## 发布前 CI 失败与修正

2026-11-14，提交 `f7853e609b039260e3598602fb3f277e1b813c1c` 的[首次 push CI](https://github.com/i-am-yimin/codex-taskboard/actions/runs/43553448633)完整浏览器测试为 220 项通过、6 项失败，该轮未通过。失败均来自 `realtime-reconnect.spec.ts` 的跨空间切换：测试仍按旧 `button` 角色查找空间选项，而现有 Radix 空间菜单的选项角色为 `menuitem`，点击等待超时。

修正覆盖进入第二空间和返回第一空间的全部相关选择器，空间菜单触发器按具名按钮定位；保留迟到事件隔离、确认前禁写、缓存切换和草稿归属撤权的原行为断言，没有跳过用例、放宽断言或修改产品代码。

同日使用本机 Chrome 执行 `pnpm exec playwright test tests/e2e/realtime-reconnect.spec.ts --project=desktop --project=compact`，整个文件的 12 个项目用例全部通过（两项目各 6 项），没有跳过。测试使用独立浏览器上下文、合成空间/任务和受控 API/事件流，运行进程清除数据库环境变量，不连接生产数据库、真实账号或日常 Codex。日志留在本机忽略目录 `.artifacts/release/2026-11-14-v0.1.14/`；此定向结果不代表后续完整 CI、原生或最终包通过。

## 安装前连接恢复拒绝基线

安装前运行中的 0.1.13 在约三小时后显示“Codex 页面恢复未确认”，重新检测仍未解除；诊断要求正常退出原窗口。观察时日常 Codex 的原 PID 与创建时间保持，没有为验收退出日常 Codex 或操作真实草稿。此为旧版实机失败基线，尚未定位触发原因，不能仅凭运行时长或进程未变推断为具体加载、结构或传输问题。

适配器会保留恢复失败并停止进一步接入；正常重启 Taskboard 可创建新的适配器并重新执行原生身份、精确页面、结构、草稿/弹窗和握手检查，但不等于上一会话的 DOM/CSP 恢复已确认。本版沿用这套生命周期逻辑。下述最终包新会话接入成功，不证明此前清理成功，也不证明长期稳定性或所有未来 Codex 版本兼容；不能将本次导航与布局发布写成该问题修复。
