# 用户中心与服务器管理

0.1.11 客户端配套声明 `accountCenter: 1` 的服务器；公开配套服务器为 `0.1.5-preview.1`。从右上角账号菜单进入“个人设置”，没有空间也可使用。最高管理员的个人资料也在这里维护。

## 个人设置

- **个人资料**：显示名称允许重名，登录仍使用邮箱。上传不超过 2 MiB 的 JPG/PNG/WebP，可调整裁剪、缩放和位置；服务端限制 1600 万像素、拒绝动画，保存去除元数据的 256×256 WebP。修改失败保留旧头像。
- **联系方式**：手机、微信、QQ 均选填，默认仅自己可见，可逐项向当前共同空间成员展示。移出共同空间后，服务端立即拒绝继续读取。成员列表头像可打开公开资料。
- **账号安全**：验证当前邮箱或申请更换邮箱，邮件链接 30 分钟内单次使用；确认前旧邮箱继续有效。更换邮箱或密码撤销其他登录和全部 Agent 令牌；密码恢复撤销所有会话。登录页有“忘记密码”，桌面可前往服务器网页办理。
- **外观与主题**：保留四套主题、明暗模式、布局、主题包及原来的预览、撤销和跨设备冲突处理。
- **设备与会话**：查看当前设备、创建时间、最近活跃时间；支持逐台撤销或退出其他设备。活跃时间最多延迟一分钟。

资料按服务器与账号隔离。个人资料和安全操作需要联网；私有联系方式和安全数据不进入离线缓存。本人名称、头像与权限在聚焦窗口时重新读取，并在在线时约每 30 秒同步；未加入空间也可同步。每个分区独立保存，失败保留输入，离开未保存页面时提示。主题继续支持本机离线选择及恢复连接后的冲突处理。

## 最高管理员

从账号菜单进入“服务器管理”；桌面与侧栏会打开服务器网页并要求正常登录，不转交登录凭据。

后台提供用户与邀请、空间治理、邮件服务、运行设置、数据库与密钥、运行日志和持久审计。始终保持邀请制，最高管理员可发出无空间账号邀请或指定空间和角色。邀请有效期 72 小时，重发使原链接失效，旧的已撤销链接不能接受。

账号停用立即撤销登录和 Agent 凭据，保留任务与历史。恢复后重新登录；必须先转移拥有的空间，不能停用自己或移除最后一名有效最高管理员。

查看空间治理列表不会打开任务内容。接管需管理员密码与原因，绑定当前网页会话、指定空间，30 分钟后失效，也可主动退出。真实成员和所有者关系不变；所有权转移要求目标为当前有效成员，普通所有者也不能把空间转给已停用成员。接管保留人工验收与状态流转规则，不提供本机进程控制。接管任务内容、空间元数据均不写入离线快照；任务、评论和结果草稿只保留在当前窗口内，退出、到期或撤权时清除相关查询和打开的任务。

## 邮件服务

托管 Compose 部署由初始化服务生成并持久保存独立 `encryption-key`。更新时先正常执行初始化服务，不能删除或覆盖原数据库密码和会话密钥。原生部署需另外设置 64 位十六进制 `TASKBOARD_ENCRYPTION_KEY`；不要复用 `SESSION_KEY`。

在“邮件服务”填写主机、端口、STARTTLS/TLS、用户名和发件人；SMTP 密码只可替换或显式清除，留空保留原值。保存需当前管理员密码。测试邮件发到当前管理员邮箱。

可通过 `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURITY`、`SMTP_USERNAME`、`SMTP_PASSWORD`、`SMTP_FROM_ADDRESS`、`SMTP_FROM_NAME` 固定配置，设置 `SMTP_HOST` 后管理页只读。证书验证保持开启。SMTP 不可用不影响已有邮箱密码登录和 CLI 恢复。

网页用户管理只发送恢复邮件，不显示恢复链接。旧网页恢复接口已停用；无法发信时，由有服务器控制台权限的维护者执行既有 `admin recovery --email <邮箱>`，新链接 30 分钟内单次有效。升级自动执行 `0010_account_center` 和 `0011_account_recovery_hardening`；后者清理旧网页恢复的明文幂等响应，不影响邀请记录或有效会话。

发件箱状态为待发送、SMTP 已接受、发送失败；SMTP 接受不代表进入收件箱。失败最多自动尝试三次，间隔约 1 分钟、5 分钟，随后可人工重试。验证链接过期需重新申请。发件箱敏感正文和 SMTP 密码均加密存储；SMTP 接受后清除邮件正文。

备份需同时保留数据库和托管状态卷/独立加密密钥。丢失加密密钥无法解密已有 SMTP 密码及待发邮件；应恢复原密钥，或明确重新配置 SMTP、重新申请邮件，不能以关闭加密或证书验证处理。改用新密钥后，须显式替换或清除 SMTP 密码；留空仍表示保留旧值，不能解密旧密码或恢复旧队列。
