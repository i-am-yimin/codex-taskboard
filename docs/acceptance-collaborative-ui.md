## 系统提醒与稍后提醒语义

桌面使用固定 `tauri-plugin-notification = 2.3.3`，保留 Tauri 2.11.5 与原直接 rand 0.8。未增加 JS 依赖或放宽宿主安全边界。UI 只有显式点击启用才请求权限；Windows 插件的 permission 返回可调用状态，并不能核实专注助手或系统显示策略。

插件 2.3.3 将原生 show 异步排队并不传播最终显示错误，因此桥接只返回 `requested` / `plugin_queued`。服务的 `deliveredAt` 记录系统提醒请求回执，不代表实际显示、系统交付或用户已读。浏览器与原生调用失败不会删除持久通知；已发请求但回执失败只补回执。真正系统弹窗及安装后应用名称/图标需另验，开发环境归属不能当正式安装证据。

领取提醒返回数据库 `EXTRACT(EPOCH FROM delivery_claimed_at)::text` 的精确代次 `deliveryToken`，客户端不将它转为 JS Date 或 Number。回执须匹配当前账号、成员资格、设备与代次；它不是密码学 nonce。稍后提醒原子清理旧领取/回执、开启新轮，旧回执和旧领取的幂等重放不能吞掉新轮。已读未处理项可再次预约，保留已读事实；已处理项拒绝预约。
