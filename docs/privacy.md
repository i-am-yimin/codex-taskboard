# 隐私与数据

自部署服务保存账号标识、密码哈希、空间成员、任务内容、评论、活动和执行结果。软件不自带第三方遥测或模型 API 调用，不向项目维护者上传任务。

用户填写的仓库 URL 会清除用户名、密码、查询参数和片段。本机目录映射、访问凭据和设备缓存保存在本机。完整 Codex 会话、源代码和认证数据库不自动上传。

浏览器在当前来源的本地存储中保留最近账号、空间、已访问看板和草稿，以便断网浏览；这些内容不是加密保险库。退出、切换账号或收到撤权结果时清理相关缓存。页面资源缓存不保存 API 响应、邀请令牌或恢复链接。断网期间无法获知新的撤权，因此缓存会标为未重新验证，只允许浏览。

任务归档可恢复。账号会话可撤销。卸载桌面启动器保留用户数据，删除数据需用户另行操作。管理员应建立备份保留策略，撤销权限无法收回用户此前自行保存或导出的副本。

示例与演示模式仅包含合成数据。诊断报告应检查并去除本机目录、账号标识及令牌后再分享。
