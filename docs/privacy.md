# 隐私与数据

自部署服务保存账号标识、密码哈希、空间成员、任务内容、多人职责、父子/依赖、评论/提及、活动、提案与人类确认、验收、成果及其验证/限制、通知与偏好、个人筛选、自动规则和时间区间。运行记录保存任务/领取/设备关联、Agent 类型、权限模式、状态、官方 session ID、脱敏错误及 unknown 人工解除审计；远程 API 不接收 PID、本机目录或模型密钥。

Taskboard 服务本身不代用户调用模型 provider，不自带第三方遥测，也不向项目维护者上传任务。用户显式启动本机 Codex CLI 或 Claude Code 后，该 CLI 会读取所映射工作区、任务提示和自身专用配置，并按其登录方式、provider 与权限模式访问网络；相关 provider 的数据处理与计费取决于用户配置。Taskboard 的“不自动上传源代码/完整会话”不表示已启动的第三方 CLI 不会向其 provider 发送上下文。

仓库 URL 在保存为任务仓库标识时移除用户名、密码、查询参数和片段。本机目录映射、运行器可执行文件/专用 home 设置、进程归属和工作目录锁保存在本机。Taskboard 不自动上传完整 Codex 桌面会话或认证数据库，不复制日常 Codex 登录到独立 CLI profile。用户主动填写到任务、评论、成果文本/链接或交接摘要的内容会进入共享服务；不要在这些字段放凭据或私有本机资料。

CLI 运行使用单独配置的 CODEX_HOME / CLAUDE_CONFIG_DIR 与本机登录。Claude CLI-login 沿用该专用目录中的官方登录；显式 API-key 模式由用户通过标准输入配置密钥，本机 SecretStore 在 Windows 使用当前用户 DPAPI 保护，仅向相应子进程注入，不回传网页/服务器或放进日志。DPAPI 不意味着工作区、任务缓存或第三方 CLI profile 全部加密，也不能防止当前用户权限下的其他程序读取已解密数据。非 Windows 开发环境的 SecretStore 仅有本机文件权限和编码，不应视为等价的加密保险库。父 Agent 和云厂商凭据不默认继承给运行子进程。

运行监督不持久化 CLI 正文输出，记录必要状态、会话关联和安全错误类别。本机仍持有运行元数据、未同步事实与用户配置，第三方 CLI 可能在其专用 profile 保存自己的历史，保留/删除应按该工具设置处理。Taskboard 重启后不根据旧 PID 夺回控制，未知状态须人工核查。

通知正文是任务信息的一部分，持久收件箱每次按本人和当前空间成员资格过滤。桌面通知由用户启用并受操作系统授权控制；启用后系统通知中心可能显示任务标题/提示，锁屏与系统保留策略由用户设备控制。静音/稍后不删除共享通知历史，撤权会阻止后续读取/投递，但无法撤回已经显示、导出或由用户另行保存的内容。

浏览器在当前来源的本地存储中保留最近账号、空间、已访问看板和草稿，以便断网浏览；这些不是加密保险库。退出、切换账号或收到撤权结果时按账号清理相关缓存。页面资源缓存不保存 API 响应、邀请令牌或恢复链接。断网期间无法得知新的撤权，缓存标为未重新验证且只允许浏览；待同步报告/运行事实不冒充服务器状态。

任务归档可恢复，账号会话可撤销。卸载桌面启动器保留用户数据，删除数据需用户另行操作；管理员应建立备份访问和保留策略。示例与演示仅包含合成数据。分享诊断、截图或备份前应检查并去除本机目录、账号、任务私密内容、密钥和令牌。
