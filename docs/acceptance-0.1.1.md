## 日常安装结果

原程序及四项 Taskboard 数据文件在正常退出后完成备份和摘要核验。新包实测通过、测试实例正常退出后，使用同一已验证安装器升级原日常安装。安装器退出 0，新版运行文件与已验收专用安装一致，注册版本与目标目录正确，原数据字节在安装前后保持。

新版使用原默认数据与 WebView 目录启动，不带测试调试参数。原三张离线缓存任务可见，凭据字节及数据语义保持；运行中的语义比较只排除缓存 `savedAt`。原服务器仍离线，配置保留，没有声明重新认证或在线同步成功。两个快捷方式均指向日常程序，其中开始菜单里预先遗留的旧测试路径已备份后修正。回退程序及 Taskboard 数据备份保留。

日常 Codex 的原进程及创建时间保持。独立测试宿主、测试 WebView 调试、API 和 PostgreSQL 监听均已释放。

## 保留的失败与范围

- 首次启动时精确页面/工作区尚未就绪，接入安全拒绝；只读观察器也曾过早检查空编辑器，未发送成功草稿请求。
- 一次工作区已就绪的接入未观察到看板就绪，程序撤回注入并恢复空编辑器；保持独立窗口可见后重试成功。原因尚未确认，未修改产品超时，也未抹去首次失败。
- UIA 在滚动后的跨进程 iframe 中给出窗外几何信息；刷新截图后按可见按钮操作。重启观察器的 PowerShell UTF-8 BOM、复用清理观察器的字段名均单独修正，原失败和同一真实进程证据保留。
- 构建资产下载的媒体类型、断点续传预算和官方 CLI 互斥参数初次失败均已保留；最终完整摘要和严格来源校验通过。没有因此调整产品超时或放宽来源要求。

固定 `v0.1.0` 标签、原五项资产及既有验收范围保持。此轮本机实测使用合成 API/PostgreSQL，不重新声明双设备、公网 HTTPS 或本地 Linux 回滚验收。Linux 隔离部署、备份恢复与内部 CA HTTPS 由该来源提交 CI 验证；另行核对了交付镜像、层摘要、入口、非 root 用户和 SPDX。
