下载后核对 `SHA256SUMS` 和 GitHub 构建来源证明。GitHub 可能将 Windows 文件名中的空格改为点号；直接按 SHA-256 校验不受改名影响。Linux 归档可用 `docker load` 导入。升级前正常退出 Taskboard 并备份本机数据；新包复验通过后再替换日常安装。
