# 桌面导航与看板布局验收

本记录对应未发布的桌面布局整合，不代表固定标签、安装器或生产服务器已经更新。保持客户端版本 0.1.13；不修改 API、数据库迁移、账号权限、宿主归属和草稿保护。

## 行为与验收条件

- 64px 侧栏只显示品牌、任务看板和任务列表，导航目标至少 44px；账号入口唯一位于顶栏。空间菜单进入“空间设置”，账号菜单进入“连接与本机”；后者直接显示原有连接功能，不混入空间分类。
- 侧栏可见时隐藏页头视图切换，顶部布局、760px 及以下和内嵌看板恢复该切换。760/761px 边界不出现重复入口或无法切换的空档。
- 五个状态按实际可用内容宽度重排，列间距 20px，列宽至少 260px；不足一列时适配内容宽度。1320×860 下为 4+1，1920px 可五列同行；页面和看板均不依赖横向裁切隐藏列。低高度窗口纵向滚动后，最后一列仍可添加任务。
- 长中文空间名、长任务标题和空状态列保持可读；四套主题、深浅模式、窄窗口和内嵌看板保留现有视觉变量。顶栏工具与主操作保持可达。
- 菜单支持方向键与 Esc，关闭回到触发器。空间设置和连接面板支持 Esc 并分别返回空间菜单、账号菜单触发器；连接失败提示进入同一连接面板，关闭后重新打开空间设置仍显示空间信息。
- 个人设置、服务器管理与退出沿用原权限；未加入空间的账号入口保持原行为。

## 回归范围

新增 `tests/e2e/desktop-shell.spec.ts` 使用合成账号、长空间名、五状态数据及独立浏览器上下文；Tauri 与伴随服务为受控替身，不连接真实账号、生产数据库或日常 Codex。断言覆盖四主题、1920/1440/1320/1201/980/761/760/480px、五列边界和无内部横滚、末列键盘操作、连接与空间分类、焦点返回、空数据、360px 内嵌和无空间权限。

现有看板、主题、响应式、控制台和 Codex 连接 E2E 的入口选择器同步到新菜单。截图由测试输出到本机忽略的 Playwright 结果目录，包括 Studio 浅色 1320×860、480×560，深色 1320×860 及内嵌 360×640 的有任务/空状态；截图需人工检查后另记结果。
