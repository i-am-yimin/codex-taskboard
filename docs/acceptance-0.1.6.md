## 失败记录与解释

- 首次使用历史验收进程记录时，原进程已不存在；检查拒绝继续。随后只读重新发现并核对当前用户的包、会话、进程创建时间、监听者及唯一页面，没有重启日常 Codex 或放宽归属检查。
- 首轮安装后直接比较了未打包主程序的摘要，因此核对停止。Tauri 源码定义并由构建日志确认，打包会把唯一的 `__TAURI_BUNDLE_TYPE_VAR_UNK` 改为 `__TAURI_BUNDLE_TYPE_VAR_NSS`。差异完整限定为这三个字节；独立提取的 NSIS 主程序与该预期结果、实际安装文件分别做了整文件比对后通过。没有重复安装或忽略未知差异。
- 首轮导航脚本把同一会话在多个导航分组中的重复节点一起匹配，唯一性检查拒绝操作。脚本改为限定到实测唯一的项目会话列表，仍要求单个目标；产品代码与候选载荷不变。首次拒绝记录和原始截图均保留。
- 冷启动观察器在 WebView 完成初始页面跳转前开始选择页面，首次命中数为零；随后等待同一实例的准确页面就绪后完成验证，没有再次启动或重新登录，没有增加产品启动或 iframe 握手时限。
- 临时 API 的 exec 会话标准输入已关闭，退出钩子未完整完成；结束本轮测试会话后，只重开本轮独立 PostgreSQL 目录以删除其精确命名的测试数据库，再正常停止集群。端口释放已另行确认，未停止日常进程。
- 原生链接提示便携 CRT 缺少 PDB 调试符号（LNK4099），构建成功；前端构建仍有既有的主 JS 超过 500 kB 与依赖注释标记提示。没有关闭检查或降低版本限制。
