## 尚未验证与限制

- 仓库 `.artifacts/toolchains` 已有便携 Rust/MSVC，但不在系统 PATH；前次仅凭 PATH 判断工具链缺失不准确。本轮已补做 Rust 测试，CI 安装器也已生成并核对来源、版本、归档摘要和安装器摘要。
- 日常 Codex `26.1016.8622.0` 中打开的 CodeMirror 文档/代码编辑器正文，也会触发 `CSP reload refused: the Codex editor contains an unsent draft`。当前检查覆盖页面中的可编辑文本，不能据此断言用户仍有聊天草稿。本轮由用户保存并关闭该编辑器标签后解除阻断，侧栏复验已通过；没有强制重载、清除内容或放宽保护。后续连接如遇此提示，按[使用手册](user-guide.md#常见问题)处理。
- 未发布 GitHub Release、客户端安装包或服务端镜像；0.1.4 已发布标签和资产保持固定。
- 本轮实机连接原已启用连接的日常 Codex，没有退出它重测首次冷启动；该流程的浏览器回归与真实侧栏证据分别记录。正式发布仍需按固定标签核对最终 Release 资产，不将 CI 候选安装包视为已公开发布。

- 生产构建提示主 JS 包超过 500 kB；构建完成，无编译错误。后续可按实际性能测量评估拆包。
