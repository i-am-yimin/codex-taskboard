# 0.1.5 开发验收

状态：源码与浏览器验收，尚未发布。客户端开发版本 `0.1.5`，配套服务端开发版本 `0.1.3-preview.1`。

## 已验证

- TypeScript、ESLint、单元测试和生产构建；常规单元测试 165 项通过，21 项依赖数据库环境的测试在常规运行中跳过。
- 独立 PostgreSQL `*_test` 数据库的服务端集成测试 6 项通过，包含主题按账号隔离、去重、幂等重试、版本冲突、非法主题拒绝、大小限制、删除回退及迁移重复执行。
- Compact 浏览器下既有看板和任务详情布局回归 5 项通过；7 项主题场景在 Desktop 配置下全部通过，其中前 6 项也通过 Compact 配置。覆盖四套主题明暗、预览撤销、布局与窄内嵌、导入导出移除、双设备同步、离线冲突、旧服务端和旧明暗配置。
- 主题场景包含延迟文件导入取消/关闭、自定义主题云端冲突，以及会话切换期间导入的回归验证；同时修复旧账号清理误取消新账号加载请求的问题。
- 生产页面离线冷重启、草稿保留、只读操作、重连和撤销会话后的缓存清理通过。
- `desktop:prepare` 与 `desktop:check-runtime` 通过，验证随包伴随服务和 CLI 在长中文路径执行。
- 四套主题的明暗看板及主题设置、360px 内嵌设置截图经过独立设计复核；复核发现的异步导入和云端主题包一致性问题已修复。静态设计检测无发现。

截图和详细运行证据保存在本机忽略目录 `.artifacts/themes/`，不包含用户真实账号、项目或草稿。本轮使用合成任务和独立浏览器，未操作日常 Codex 的聊天或编辑器。

## 尚未验证与限制

- 本机缺少 Cargo / Rust 工具链，未运行 Rust 测试、生成新 Windows 安装器或执行真实安装升级验收。
- 未发布 GitHub Release、客户端安装包或服务端镜像；0.1.4 已发布标签和资产保持固定。
- 浏览器与 API 同步证据不能替代真实安装后的桌面与日常 Codex 侧栏联调验收。
- 自定义主题只做声明式格式和值范围校验，作者仍需检查文字对比度。主题包不含图片、远程字体、任意 CSS 或执行代码。
- 生产构建提示主 JS 包超过 500 kB；构建完成，无编译错误。后续可按实际性能测量评估拆包。
