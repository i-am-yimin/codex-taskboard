官方路线补充了可搬移的完整合成本地插件包，实际当前 CLI 已识别服务、工具和 HTML 资源。首轮真实 UI 观察在原生 TCP 目标探测超时后停止；此后新实例的完整身份复核通过，实际个人目录和插件详情页显示了该插件。静态 HTML 的首次打开出现“未能显示”，补齐 MCP Apps 初始化握手并采用新的资源 URI 后，原型 `0.0.2` 已在当前真实独立宿主显示 global 界面、“宿主桥接已就绪”状态，并成功展开合成任务。

原型的 SDK、stdio、中文/空格缓存搬移及浏览器初始化正负路径共 6 项测试通过；类型与相关 ESLint 通过。实机交互同时核对原生身份、精确主页面、宿主生成的唯一 MCP App sandbox 目标及其默认执行上下文。未修改 CSP、权限、版本或超时门禁；导航后的复核曾再次失败，停止后新的完整原生复核恢复通过才继续。
