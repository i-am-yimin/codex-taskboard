前一轮类型与 ESLint 通过。完整 Vitest 256 项通过、49 项数据库集成测试因未提供独立测试数据库而跳过，不能写成通过；本次没有服务端或持久化变更。连接流程 e2e 在桌面和紧凑窗口共 26 项通过。原生模块单独执行 30 项通过、4 项按既有条件忽略；完整 Tauri 检查仍单列。官方原型的 SDK 内存/stdio 客户端验证共 2 项通过。此后主页面重载监测修复须另行回归，不沿用旧结果当作新源码通过。

当前真实 `26.1021.3705.0` 在原登记的独立测试 profile 中通过原生句柄/包/监听者/页面身份、结构自检、合成 iframe 侧栏接入、完整标题栏与工作区互斥、编辑器/样式保留、外部刷新恢复以及卸载后的实际 CSP enforce。最初因新增 active-page 容器而拒绝，补明确契约后通过；未将当前版本加入侧栏白名单或自动草稿清单。此处是源码适配器加原生模块诊断，尚非最终安装包证据。

新增自动监测后的真实复验曾在外部重载失败。协议追踪确认，原恢复循环只等到壳层/主内容，随后完整契约检查时编辑器尚未挂载，清理因工作区未就绪而明确拒绝。已保留失败；修复关联精确主 frame 的加载生命周期，并让恢复循环等到完整契约。大于监测周期的延迟脚本与延迟编辑器回归 24 项通过，先前相关适配器回归 66 项通过。修复后真实接入、视图与外部恢复已通过；500ms CSP 事件探针未观察到事件，另一个事件/请求联合诊断确认实际 enforce 且合成服务器收到 0 次请求，最终完整复验改为等待精确探针来源的 enforce 事件，单列结果。

最终修复的类型、相关 ESLint、生产构建、`desktop:prepare` 和 `desktop:check-runtime` 通过；完整 Tauri `cargo test --locked` 为 45 项通过、4 项按既有条件忽略。桌面资源在中文长路径、ES module 上级目录中实际执行，通过随包伴随服务和 CLI 检查。

原始日志和实机记录保存在本机忽略目录 `.artifacts/acceptance/2026-10-29-codex-compatibility/`。浏览器测试曾在服务启动阶段被本机代理误转发回环请求，针对测试进程补 `NO_PROXY` 后同一用例通过，未修改测试阈值。
