# 0.1.2 日常 Codex 接入验收

日期：2026-10-24。状态：验收中，尚未发版。

本版解决日常已经打开 Codex 却只能另开独立环境的问题。首次从连接入口启用后，使用连接快捷方式打开同一个日常环境；不指定独立 profile，不复制登录资料。已运行但未启用连接的窗口需由用户保存工作并正常退出一次。明确保留独立测试路线以及它原有的自动草稿能力；日常模式不推测自定义 Codex home，暂使用手动粘贴草稿。

修复前两次宿主测试的失败记录保留：首次握手超时，第二次外部刷新恢复握手超时，均撤回注入；没有据此放宽握手时限或删除保护。就绪响应从 React 普通 effect 改为布局 effect，确保提交完成即可响应，不等待隐藏 iframe 的绘制。侧栏适配、就绪与 CSP 生命周期回归共 59 项通过，包含隐藏原生 iframe 的首次提交和刷新测试，以及准确区分接入失败原因的测试。

一次早期测试中，`Browser.close` 仅关闭渲染窗口，测试主进程仍存活。该独立测试进程的精确身份、创建时间和合成草稿备份核实后才清理，原始记录保留；它不计入正常退出证据。随后另用应用自身退出入口独立完成退出和重启验收，并核实持有的进程句柄退出。
