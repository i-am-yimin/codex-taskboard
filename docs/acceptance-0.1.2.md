# 0.1.2 日常 Codex 接入验收

日期：2026-10-24。状态：验收中，尚未发版。

修复前两次宿主测试的失败记录保留：首次握手超时，第二次外部刷新恢复握手超时，均撤回注入；没有据此放宽握手时限或删除保护。就绪响应从 React 普通 effect 改为布局 effect，确保提交完成即可响应，不等待隐藏 iframe 的绘制。侧栏适配、就绪与 CSP 生命周期回归共 59 项通过，包含隐藏原生 iframe 的首次提交和刷新测试，以及准确区分接入失败原因的测试。

日常窗口首次从原 Windows ChatGPT 图标重开时没有连接参数；改用已验证的桌面连接入口后，真实进程带回环连接参数，沿用正常环境。首次自动接入未成功，界面也出现并发安装的生命周期错误；同一实际产品随后接入成功，人工检查确认侧栏看板已绘制且已同步，真实用户草稿未被修改。新增修复在改变 CSP 前有界等待尚未挂载的工作区，并让同一适配器的并发接入请求共用一次安装；草稿、弹窗、目标漂移和重复标记继续直接拒绝。完整 CI 曾暴露登录页被当成加载中的工作区而超时，现保留登录页的即时拒绝，并在独立 Chromium 中补测首次工作区延迟挂载。适配器、CSP 生命周期与原生控制相关回归 67 项通过；修复的实际安装与最终标签包仍待验收。日常产品正常退出、侧栏撤销后的实际 CSP enforce，以及重开 Taskboard 复用同一 Codex 进程均已另行实测通过。

实际安装候选的日常连接检测能正确提示首次重开，但点击接入后，Tauri 以字符串返回的拒绝说明被界面替换为通用错误。该失败记录保留；界面现统一保留原生字符串与 Error 消息，端到端回归同时覆盖两种拒绝形态及连接检测失败，本地紧凑窗口 4 项通过。修复后的 `f1ca9d4` 已在日常真实安装中通过原生按钮复测，完整重开说明保持；对应三项 CI 也全部通过。

首个独立 Taskboard 界面测试在伴随服务正常停止、无草稿和待提交数据并备份后回收 GUI 进程，该回收不计入正常退出证据。随后在日常安装中另行验证新增的维护退出入口：退出优先于同时传入的连接参数，真实桌面与伴随服务结束，原有 Codex 保持。合成专用 PostgreSQL 已正常停止，其无状态 API 在数据库停止后受控回收；最终标签升级验收须重新准备有效的旧版合成登录。

一次早期测试中，`Browser.close` 仅关闭渲染窗口，测试主进程仍存活。该独立测试进程的精确身份、创建时间和合成草稿备份核实后才清理，原始记录保留；它不计入正常退出证据。随后另用应用自身退出入口独立完成退出和重启验收，并核实持有的进程句柄退出。
