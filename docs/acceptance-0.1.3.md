# 0.1.3 明确运行时格式与日常 Codex 接入验收

日期：2026-10-24。状态：验收中，尚未公开。

0.1.2 的实际标签安装器在较长中文目录中首次启动失败。Node 22 将带 CommonJS 内容的 `.js` 当作 ES 模块，尽管就近的 `package.json` 声明了 CommonJS。最小程序复现相同路径下的包范围识别问题；明确的 `.cjs` 文件名能加载原字节。0.1.2 保持草稿，标签和 5 项资产不修改。失败现场与回收边界见 [0.1.2 记录](acceptance-0.1.2.md)。

本版将 Windows 随包伴随服务和 CLI 的入口改为 `.cjs`，同时更新原生启动器、CLI wrapper 和直接入口识别。Windows CI 与发布流程增加实际打包检查：从较长中文路径与 ES module 上级目录运行，不依赖就近的运行时清单，验证伴随服务健康请求、正常停止和 CLI 帮助。
