# ADR 0005：声明式主题与账号同步

状态：接受（0.1.5）。

主题是个人账号偏好，与任务空间无关。四套内置主题共享组件、语义变量与两种导航布局，不允许插件替换页面或执行代码。

主题包使用 v1 JSON，继承内置主题并覆盖受限变量。颜色仅接受六位十六进制，圆角和字体等使用有限范围或枚举。无任意 CSS、HTML、脚本、外部资源或宿主 DOM 权限。格式化后按固定键顺序计算 SHA-256，内容相同的包去重。

PostgreSQL 的 `user_appearance` 保存选择与版本，`user_themes` 按账号保存主题包。写入沿用事务、幂等键、鉴权和 If-Match 检查；上传、选择和删除共用用户行锁，删除正在使用的主题时原子回退到玻璃。迁移编号为 `0004_user_themes`。

浏览器直接使用现有会话；桌面和内嵌页面经伴随服务中转，CLI/Agent 不获得主题写权限。现有 CSP、来源和 nonce 校验保持有效。

伴随服务提供只读 `/v1/browser/identity`，返回当前服务器地址和账号 ID，沿用全局来源及 renderer/embedded 能力凭据校验。内嵌同源 GET 不携带 Origin，因此不复用要求 Origin 的配置接口；原 `/v1/browser/upstream` 的配置读写校验保持不变。此接口不返回会话或远程凭据，CLI 能力不能访问。

客户端按服务器地址和账号缓存选择、主题包、待同步请求及其幂等键。离线应用仅改变本机外观；恢复连接后以原版本重试，冲突由用户选择云端或本次外观。登录、窗口激活及每 30 秒检查云端配置。登出清理对应账号缓存。

代价：首次在新设备使用自定义主题需联网，跨设备同步可能有最多 30 秒延迟；旧服务端只能保留本机外观。首版不提供主题商店、外部素材和可执行扩展。
