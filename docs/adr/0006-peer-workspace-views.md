# ADR 0006：看板与会话作为同级视图

日期：2026-10-25。状态：0.1.7 候选实现。

## 问题

0.1.6 在会话正文内插入绝对定位看板，导航后自动收起。用户复验发现会话标题栏仍穿透，两个入口同时高亮。实际宿主的固定标题栏是主内容区之外的兄弟节点；提高看板层级不能建立同级导航关系。

## 决策

- 将看板作为完整原生工作区的兄弟节点，使用正常布局流。进入看板时，将原工作区临时设为不可见、`inert` 和 `aria-hidden`，包括会话标题栏、正文、编辑器及其工具。全局导航和窗口操作保持可用。
- Codex `26.1016.8622.0` 使用实测的完整工作区标记；必须唯一、包含已验证的内容区且不包含侧栏。缺失、重复或越界时拒绝注入，不回退到覆盖层。其他既有宿主沿用各自已验证的内容边界，不增加版本清单。
- 看板选中时暂挂原导航项的 `aria-current` / `aria-selected` 呈现，并用本实例样式去除其选中背景。宿主内部的 thread active/selected 标记保持，原视图、编辑器和 iframe 均不卸载。
- 再次点击当前看板保持当前页；具体会话、原生导航或宿主选择变化恢复会话视图。无关标题更新和同一选择的重新呈现不切换页面。
- 保存并按所有权恢复原属性和样式，只恢复仍为本实例应用值的部分，不覆盖宿主期间产生的新状态。工作区移除、接入失败或卸载时恢复并清理本实例节点、监听器、观察器及样式。
- 隔离环境的草稿操作通过绑定当前代次的私有视图控制器先返回会话，继续执行原项目和空编辑器验证；拒绝时恢复同一看板。日常模式仍不自动填写草稿，身份、来源、nonce 和 CSP 规则不变。

## 验证

独立 Chromium 夹具必须包含内容区外的固定标题栏，验证完整视图互斥、单一当前页、重复点击、草稿/DOM 保留、原生状态更新及清理。模拟、实际安装和真实宿主证据分别记在 [0.1.7 验收](../acceptance-0.1.7.md)中。
