# ADR 0007：协作任务与运行分离

日期：2026-10-25；2026-10-26 补充实际实现。状态：接受，源码已实现；实机与发布证据单列。

## 背景与决策

单负责人/checklist/执行记录无法表达多人职责、独立子任务验收和真实进程状态。保留 assigneeId 为一个总负责人，新增多人职责、明确验收人、父子与依赖；简单 checklist 不强制升级。任务角色始终与当前空间权限取交集，不能赋权。五种 semantic 不变，阻塞独立；退回、取消、重开使用有原因的命令，人类与 Agent 均不能 PATCH 绕过验收。

领取、执行报告和真实运行分离。新 claim 对应 execution phase claimed，不伪造 OS 运行。叶子各自领取/提交/验收，父负责人在必要子任务完成后提交独立 integration execution，父仍须人类集成验收。Agent 不能验收或确认任何拆分/需求/决策提案；提案来源按认证上下文记录，原 payload 与人类调整后的 confirmedPayload 分别保留。

服务端沿用事务与空间行锁，关系与父验收使用同一锁域，递归检查父子和依赖的混合等待环。状态、活动、幂等响应与通知同事务提交；数据库任务外键和服务端空间校验共同维护边界，不增加另一套项目权限。通知持久化，SSE 仅提示刷新；桌面投递用当前轮次的设备 lease/token，稍后使旧轮次失效，系统弹出不等于已读。

Codex CLI 与 Claude Code 通过独立 AgentRunner 监督，不依赖桌面 AgentAdapter。CLI 使用专用 profile/用户选择的认证，本机密钥由 Windows 当前用户 DPAPI 保护；不复制日常 Codex 登录。默认 read-only，工作区开发需显式 workspace-write，网页与远程 API 不能指定任意命令、PID、目录或凭据。每个伴随服务对同仓库一个映射、同规范 cwd 一个活动运行；不自动建立 worktree。不同账号/设备可各自映射独立目录并行。

运行状态来自真实本机观察；重启后不夺回旧 PID，unknown 不能伪造成成功或取消。人类核查停止后可记录确认人/时间/理由，仅解除阻塞，保留 unknown 历史。恢复需实际官方 session ID、同设备同 runner 的已结束前序 run，并创建新 run。运行退出不等于提交或验收。

自动化使用真实依赖、dueAt 和等待区间，onReady 启动有界 worker、onClose 清理，唯一 occurrence 抵抗多实例重复。周期采用明确起点和固定 intervalHours，不承诺 cron/本地墙钟语义。阻塞/待验收只累计未归档的活动任务时间，终态/归档关闭，重开/恢复新开；无法复原的历史区间标 legacy_unknown，不伪称精确统计。

## 兼容与代价

0005—0009 增量迁移保留旧任务、评论、执行和发布资产。旧 running execution 回填业务 claim 并转 claimed，不制造真实 run；旧待验收任务缺 reviewer 时人工补派。新任务默认创建者负责，历史缺失责任不自动提升权限。旧客户端危险状态 PATCH/缺需求修订的提交会被拒绝，需客户端与服务端协调升级；当前没有额外远程协议协商层。

任务材料是链接/文本及验证元数据，不自动同步 GitHub PR，不搬运完整宿主会话。卡片当前没有参与/依赖/子任务聚合计数，详情提供完整关系。凭据、本机运行归属与工作目录锁留在本机。代价是跨设备继续任务依赖共享交接摘要，未知进程必须人工核查，而不能凭端口/PID或旧缓存宣称恢复。

具体 API、实施分工及验收矩阵见[实施设计](../collaborative-workflows-design.md)，运行设置与证据范围见[Agent 运行](../agent-runners.md)。ADR 0003/0004 的桌面宿主身份、原登录与草稿保护边界保持有效。源码与受控子进程/浏览器验证不能替代已登录官方 CLI、原生系统通知或最终安装包验收。
