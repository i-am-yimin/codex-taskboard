# ADR 0009：账号中心与实例治理

状态：接受（0.1.11 开发候选，服务器 0.1.5-preview.1）。

账号以服务器地址与用户 ID 识别，显示名称、登录邮箱均可变。个人资料、空间成员角色及实例最高权限是三个独立概念。沿用 `instance_admin`，不创建第二套角色系统。首期保持邀请制，不增加公开注册、第三方登录、自定义权限或永久删除账号。

`0010_account_center` 增量迁移扩展资料版本、联系方式、邮箱验证、设备活跃与邀请撤销，新增头像、验证请求、SMTP、加密发件箱、接管及持久审计。历史账号的邮箱待验证，不强制重新登录，不改变原用户 ID、密码、任务、主题或有效会话。

联系方式默认私有，逐项允许当前共同空间成员读取。本人资料与公开资料接口分离，通用 User 不携带私有联系方式。资料与头像共享用户行锁和版本；头像仅接受受限大小、像素和格式的静态位图，由服务端生成去除元数据的 256×256 WebP，保存于 PostgreSQL，避免首期引入对象存储。

邮箱变更先验证原密码、确认新邮箱，再原子更换；保存发起会话，以保留当前会话并撤销其他会话及全部 Agent 令牌。找回密码撤销所有会话。验证请求仅存令牌哈希。邮件写入事务发件箱，SMTP 密码和含链接的发件箱正文由独立 `TASKBOARD_ENCRYPTION_KEY` 以 AES-256-GCM 加密，SMTP 接受后清除正文；失败有界重试。环境变量优先于管理页配置，管理页不回显凭据。已有托管密钥保留，新密钥由初始化容器单独生成。

实例治理只允许浏览器人类会话。空间内容需要密码与原因创建 30 分钟、绑定 session/space 的接管授权；不插入或修改成员关系。统一空间授权与任务授权、空间列表及 SSE 复核接管，仍遵守任务状态机和人工验收规则。接管不允许冒用他人身份或启动远程本机进程；所有权转移使用专用命令并要求目标为有效真实成员。撤销、过期、降权和会话失效关闭访问，内容不进入离线快照。

用户治理、空间创建和所有权转移使用一致的治理锁；取得锁后重新核对创建者会话或接收所有权的成员状态，防止停用与创建/转移竞态留下失效所有者。禁止停用自己、移除最后有效最高管理员，空间所有者停用前必须转移所有权。停用不删除历史，恢复不复活旧设备凭据。接管任务草稿只使用窗口内状态，普通离线快照也过滤接管空间的元数据。审计独立持久化，记录动作、操作者、目标、结果和原因，不保留密码、令牌或联系方式正文。

桌面和内嵌页面沿用伴随服务浏览器会话，增加精确接口白名单及有界头像二进制转发；不向 CLI 放行账号操作，不缓存私有资料。最高权限后台仍在服务器网页运行。旧服务端缺少 `accountCenter: 1` 时客户端明确提示升级，原主题能力保留。增加 Nodemailer 与 sharp 仅用于服务端发信和图片归一化，桌面伴随进程不引入这两项运行能力。
