# ADR 0008：按结构契约接入 Codex 侧栏

日期：2026-10-29；更新：2026-10-30。状态：已实施，固定 0.1.9 本机实装已核验；0.1.10 新增缓存页面契约，源码和真实独立宿主已核验，最终安装包实装另验，见 [0.1.10 记录](../acceptance-0.1.10.md)。0.1.9 当时的多编辑器拒绝及普通恢复限制保留于[实装记录](../acceptance-0.1.9.md)，此前源码证据见[兼容验收](../acceptance-codex-compatibility.md)。

## 背景

精确版本白名单在补丁升级时先行拒绝，尚未检查当前页面。维护单位改为有限结构契约，减少用户逐版等待。此决策替代 ADR 0003 的版本启动/侧栏门禁、ADR 0004 的侧栏版本门禁及 ADR 0006 的按版本选择边界；其余身份、恢复、草稿和数据保护约束继续有效。

## 决策

1. 原生层仅发现当前用户安装、精确发布者/包名/路径一致的唯一 MSIX。版本须为四段 u16，不再以补丁号授权启动。真实进程句柄、PID/创建时间、用户/会话、包身份、回环监听者、唯一主页面和精确 WebSocket 仍逐次核验。启动成功不授予侧栏权限。
2. 生产伴随服务固定使用 `structureCheck: auto`；浏览器不能提交版本、selectors 或目标。适配器先核验私有原生会话，再对绑定页面只读自检。返回节点关系、文档代次及草稿/弹窗布尔值，不返回会话、项目名称或草稿文字。
3. 维护五套互斥契约：单导航旧壳层、双导航语义主内容壳层、双导航完整工作区壳层、active-page 容器壳层，以及真实 `26.1021.3705.0` 观察到的显式当前/隐藏缓存页面壳层 `active-page-cache-shell-v1`。前四套继续要求唯一编辑器；第五套要求唯一当前页，每页直接隶属同一根且只有一个完整 placement/main/editor，全部 main/editor 均归入已验证页面。隐藏页必须显式为 false，外层 display:contents、内层 display:none 且无布局矩形；显式 true 的单页也只匹配第五套。侧栏在工作区之外，新版标记不能降为旧模板；标题栏越界、重复当前页、可见缓存页和未知外部兄弟区域均拒绝。仅容许已观察的不可见状态节点、本实例节点及 active-page 壳层的空、不可交互绝对定位背景。
4. 自检通过只返回 `structure-ready`。接入前再次核验同一契约、进程/页面和修改前保护，按原有 CSP opt-in、受保护重载、来源/nonce 握手完成后才返回 `installed`。版本仅用于诊断及独立草稿验收记录。
5. 自检结果不作为缓存授权。安装、重载恢复和已安装探测均重新检查；重载中不显示已接入。第五套只允许当前 main 已有、editor 尚未挂载的已观察中间态报告 `loading`，不授予接入能力；已有看板立即恢复原生视图，保留同一入口/iframe，入口禁用并标记忙碌，每 100ms 自检，在原宿主就绪预算内等到完整结构。超时或未知漂移撤回并清理，本实例异步监测确认 CSP 恢复。切换后再次打开看板，重新解析当前完整工作区，不能继续隐藏旧缓存页。恢复失败单列 `restoration-unconfirmed`，卸载清理监测与定时器。
6. 单独报告未连接、归属失败、目标变化、传输未就绪、结构缺失/歧义、草稿/弹窗阻止和恢复未确认。已安装探测可触发本实例的安全清理；安装前的结构探测本身不修改页面。
7. 日常模式没有 `codexHome`，始终手动复制。独立模式自动草稿继续要求历史实测版本、精确项目、DOM/模型空编辑器、无弹窗及实际写入确认。侧栏契约通过不能增加草稿权限。历史显式 marker 接口只供原有隔离夹具/诊断，未知版本不能通过该接口绕开契约。
8. 任务 API、CLI/Claude Code 运行、协作和通知继续使用既有独立权限与运行器，不依赖侧栏自检。独立看板是可用的工作入口，不当作侧栏成功。
9. CSP 刷新检查覆盖所有缓存编辑器，单空段落（无子节点或只有一个 br）以外的文字、空格、图片和富文本均视为草稿。未知多编辑器不能借恢复路径授权刷新；原单编辑器的受保护 CSP 恢复路径保留，不据此允许新注入。
10. 预期重载期间暂不可观测只报告 unchecked，不提供能力；在同一原宿主就绪总预算内等待原生证明恢复。启动器空 session 最多完整复核一次、总预算仍为 4 秒；短时 negative proof 可重新取得完整 description 并验证一次，总预算仍为 8 秒。每次都要求全部身份字段一致和新的原生 positive proof，持续失败、替换、格式错误和超时均拒绝，不复用缓存成功或改绑目标。

## 取舍与官方路线

这是对私有 DOM 的有限支持，不能承诺未知结构或协议永远兼容。新契约必须增加正负夹具并取得独立宿主证据；同一契约的补丁不需手动追加版本。源码夹具、运行时自检、真实宿主功能和最终安装包是四种证据。

官方 Extensions 的 global/thread UI 入口目前明确描述 ChatGPT。先做合成数据原型并核对目标宿主，只有 Codex 真实显示并可使用所需 UI 才能替代本路径。MCP 工具发现不能当作侧栏 UI 验收。

2026-10-29 的[合成原型实机记录](../codex-plugin-ui-probe.md)已证明当前独立 Codex 的 global 和 thread 界面显示、握手与展开交互。thread 入口在已有合成会话的右侧新标签页“更多工具…”中。业务账号、撤权与同步仍未验收，尚不替代本 ADR 的生产侧栏路径。
