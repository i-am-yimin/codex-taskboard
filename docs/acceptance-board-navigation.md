# Codex 侧栏看板导航收起验收

日期：2026-10-25。范围：源码修复、本机候选与固定标签 0.1.6 安装验收；已公开预发布，三类证据分别记录。

补充：0.1.6 的“导航后自动收起”检查没有验证完整会话标题栏和单一导航选中态，用户复验仍出现覆盖。本记录保留原检查范围；同级视图的修正和新增验收见 [0.1.7](acceptance-0.1.7.md)。

## 期望行为

- 打开看板后点击原生侧栏中的已有会话、其他会话、项目或“新聊天”，看板收起，入口恢复未选中状态。
- Enter / Space 激活原生入口、宿主在相同 URL 下切换选中会话，以及同文档导航、前进/后退均能收起看板。
- 自动收起不抢走宿主焦点，不修改聊天草稿；看板 iframe 保持挂载，重新打开可继续未保存内容。
- 看板内部操作、会话标题更新、后台更新项目展开属性、未变化的选中属性不触发自动收起。
- 卸载和重复接入清理本次的点击、导航和选择观察器；保留原有 Esc、再次点击入口及位置样式恢复行为。

## 自动验证

`tests/desktop.iframe-ready.test.ts` 使用独立 Chromium、两个回环服务和合成宿主，复用实际注入脚本及 React 就绪响应模块。新增三个回归在修复前全部失败：原生点击后仍覆盖、选中会话变化后未收起、同文档导航后未收起。

- 适配器、iframe 就绪、CSP 生命周期与重复接入定向回归：4 个文件、72 项通过，包含新增三个回归。
- `pnpm test:e2e tests/e2e/codex-connection.spec.ts`：Desktop / Compact 共 24 项通过，覆盖连接、等待/取消、重试、启动偏好及握手失败提示。原生调用为模拟，没有操作日常 Codex。
- 合成宿主嵌入实际演示看板的截图：1280px 浅色、742px 浅色、1280px 深色三种组合完成打开/切换会话后的共六张截图。已检查聊天恢复可见、入口复位、原焦点与合成聊天草稿保留；它们不证明真实宿主布局。
- 742px 深色截图因辅助页面在 10 秒内未就绪而未完成；单独 Vite 补采也在首个场景就绪超时，没有计为通过或扩大产品握手时限。辅助脚本、截图及失败记录保存在忽略目录 `.artifacts/acceptance/2026-10-25-board-navigation/`。
- `pnpm check` 通过：TypeScript、ESLint、完整测试及 Web/服务端生产构建均完成；测试 168 项通过、21 项因未配置独立数据库而跳过。本次没有数据库或 Rust 改动，没有运行数据库集成、离线及 Windows 安装包验收。
- 首次类型检查发现回归测试对 `HTMLElement | SVGElement` 调用 `click()` 的类型错误，改为派发点击事件后通过。构建仍有既有的主 JS 超过 500 kB 和依赖注释标记提示，无编译错误。

0.1.6 安装验收前的实机只读观察发现宿主使用自己的 thread active/selected 属性，已补充两个属性与对应回归；具体结果继续记在[0.1.6 验收记录](acceptance-0.1.6.md)。上述 168 项是前一提交的证据，不代替本次补充后的检查。

## 实机与交付边界

上文 168 项源码测试和模拟页面属于最初修复提交，只验证当时注入脚本的导航、焦点和生命周期。后续 0.1.6 本机构建已在实际安装后通过独立数据环境及日常账号的真实宿主验证，最终源码测试为 170 项通过；两轮证据不混用。

实际安装版在兼容日常 Codex 中通过当前/其他会话、键盘 Enter、新聊天和项目导航，保留原登录及真实草稿。未提交任务表单的保留使用合成账号验证，数据库脚本仅指向独立测试库。完整安装器摘要、来源、失败记录、冷启动与清理范围见[0.1.6 验收记录](acceptance-0.1.6.md)；宿主版本、归属、CSP 与 nonce 校验沿用现有规则。
