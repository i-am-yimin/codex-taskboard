## 期望行为

- 打开看板后点击原生侧栏中的已有会话、其他会话、项目或“新聊天”，看板收起，入口恢复未选中状态。
- Enter / Space 激活原生入口、宿主在相同 URL 下切换选中会话，以及同文档导航、前进/后退均能收起看板。
- 自动收起不抢走宿主焦点，不修改聊天草稿；看板 iframe 保持挂载，重新打开可继续未保存内容。

- 卸载和重复接入清理本次的点击、导航和选择观察器；保留原有 Esc、再次点击入口及位置样式恢复行为。
